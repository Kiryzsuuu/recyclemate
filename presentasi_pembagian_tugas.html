  • Marketplace jual-beli produk upcycle (daur ulang kreatif)

🗂️ Pola Arsitektur

  • Screens → UI halaman (StatefulWidget)

  • Widgets → komponen UI reusable

❓ Pertanyaan yang Mungkin Ditanya

Q Bagaimana cara app tahu user sudah login atau belum?
SplashScreen cek FirebaseAuth.instance.currentUser — kalau tidak null berarti sudah login, langsung redirect ke /home. Kalau null, redirect ke /login.
Q Apa perbedaan peran buyer, seller, dan admin dalam kode?
Field role di Firestore collection users. UserModel punya getter isAdmin (role == 'admin') dan isSeller (role == 'seller' atau 'admin'). HomeScreen cek getter ini untuk tampilkan menu yang berbeda.
Q Kenapa ada fungsi _ensureAdminAccount() di main.dart?
Supaya akun admin otomatis terbuat saat pertama kali app dijalankan, tanpa perlu setup manual. Fungsi ini cek Firestore collection app_config/setup. Kalau sudah ada flag adminCreated: true, fungsi langsung berhenti — tidak bikin akun ulang.

❓ Pertanyaan yang Mungkin Ditanya

Q Kenapa filter search dilakukan di client bukan di Firestore?
Firestore tidak mendukung full-text search secara native. Solusinya: semua produk diload dulu dari Firestore, kemudian disaring di sisi Flutter menggunakan method String.contains(). Untuk skala besar bisa pakai Algolia atau Typesense, tapi untuk prototype ini cukup.
Q Apa itu FutureBuilder dan kenapa dipakai?
FutureBuilder adalah widget Flutter untuk menampilkan UI berbeda berdasarkan state dari sebuah Future (async). Saat loading → tampilkan spinner. Saat error → tampilkan pesan error. Saat data ada → tampilkan grid produk. Ini cara idiomatis Flutter untuk handle async data.
Q Bagaimana cara navigasi ke halaman detail produk?
Pakai Navigator.pushNamed(context, '/detail', arguments: product.toMap()). Di main.dart, route /detail didaftarkan di onGenerateRoute karena butuh argumen dinamis (data produk), berbeda dengan route statis lainnya.

class StorageService { static final _storage = FirebaseStorage.instance; // Upload file, kembalikan URL publik static Future<String> uploadFile( File file, { String folder = 'products', }) async { // Buat path unik pakai timestamp final path = '$folder/${DateTime.now().millisecondsSinceEpoch}'; final ref = _storage.ref(path); await ref.putFile(file); // Dapatkan URL download yang bisa diakses publik return await ref.getDownloadURL(); } }

💻 Kode Kunci — Create Product

lib/services/api_service.dart (createProduct)
static Future<ProductModel> createProduct( Map<String, dynamic> data) async { final user = _auth.currentUser; if (user == null) throw Exception('Belum login.'); // Ambil profil user untuk info crafter final userDoc = await _db .collection('users') .doc(user.uid) .get(); final docData = { ...data, 'crafterId': user.uid, 'crafterName': userDoc['name'], 'isActive': true, 'createdAt': FieldValue.serverTimestamp(), }; // Simpan ke Firestore final docRef = await _db .collection('products') .add(docData); return ProductModel.fromFirestore( await docRef.get()); }

❓ Pertanyaan yang Mungkin Ditanya

Q Bagaimana cara foto produk disimpan? Langsung ke Firestore?
Tidak. Foto tidak disimpan langsung di Firestore karena Firestore hanya menyimpan teks/angka. Foto diupload ke Firebase Storage menggunakan StorageService.uploadFile(), kemudian URL hasil upload (string) yang disimpan di Firestore field imageUrl.
Q Apa itu soft delete dan kenapa dipakai?
Soft delete artinya produk tidak benar-benar dihapus dari database. Hanya field isActive yang diubah menjadi false. Keuntungannya: data pesanan lama yang mereferensi produk tersebut tidak rusak (referential integrity), dan admin bisa melihat riwayat produk yang sudah dinonaktifkan.
Q Bagaimana proses dari buyer menjadi seller?
Buyer pergi ke halaman OpenStoreScreen, isi form toko, lalu submit. Di backend, FirestoreService.createStore() membuat dokumen baru di collection stores DAN mengupdate field role user di collection users dari 'buyer' menjadi 'seller'. HomeScreen kemudian menampilkan menu toko yang sebelumnya tersembunyi.

❓ Pertanyaan yang Mungkin Ditanya

Q Bagaimana keamanan admin? Apa sembarang user bisa akses /admin?
AdminScreen cek UserModel.isAdmin di initState(). Kalau bukan admin, langsung redirect ke home. Di HomeScreen juga, tombol admin hanya muncul kalau _isAdmin == true. Role admin disimpan di Firestore dan tidak bisa diubah user sendiri.
Q Apa itu Future.wait dan kenapa lebih baik dari await berurutan?
Future.wait([...]) menjalankan semua query secara paralel. Kalau 4 query masing-masing butuh 200ms, dengan await berurutan total = 800ms. Dengan Future.wait, total hanya ~200ms karena semua berjalan bersamaan. Ini teknik optimasi penting untuk dashboard statistik.
Q Bagaimana cara admin bisa ubah konten banner homepage?
Admin punya tab "Site Settings" di AdminScreen. Saat submit, data diupdate ke Firestore di app_config/site_settings. HomeScreen membaca dokumen yang sama menggunakan FutureBuilder setiap kali dibuka — jadi perubahan langsung terlihat tanpa update app.
